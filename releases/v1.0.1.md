## Piano Practice Companion 1.0.1

### What's new

- **Name the progression plays each question by itself.** No need to press Play: the passage starts as soon as the question appears, after *Next* and at the start of a level. (When the exercise is opened straight from a link, the browser asks for one tap first: press Play once.)
- **The back button works in the web demo on phones too.** In a phone's browser, back now closes the last opened menu (Settings, Display, the song list...), then returns to the main menu, as in the Android app.

### How to get it

| Device | What to do |
|---|---|
| Computer, tablet or phone | open the [web demo](https://dylan-sam.github.io/piano-practice-companion/) in a browser: nothing to install |
| Android phone (Android 7.0 or newer) | download **piano-practice-companion-debug.apk** below, open it, allow the install when Android asks, then tap **Install** |

Already have 1.0.0 on Android? Install this APK over it; your tunes and settings are kept. If Android refuses, uninstall the old version first (export your playlists before, as uninstalling erases them).
